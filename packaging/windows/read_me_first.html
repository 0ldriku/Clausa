Clausa {{VERSION}}

Clause-based fluency measures for learners' speech

Clausa analyses recordings of learners speaking and gives nine fluency measures for each one. Everything runs on your PC. Nothing is uploaded.

Before you start

  • 64-bit Windows 11, or Windows 10 with Microsoft Edge.
  • An NVIDIA graphics card with 8 GB or more makes Clausa several times faster. Without one, it takes a few minutes per recording.
  • 16 GB of memory or more (32 GB without an NVIDIA card).
  • {{FREE_GB}} GB of free space.
    • {{MODELS_NOTE}}
  • Keep the Clausa folder out of OneDrive, Dropbox and Google Drive.

Set up

1

Extract

Right-click the zip and choose Extract All, then click Extract.

2

Double-click Clausa.exe

If Windows says it protected your PC, click More info, then Run anyway.

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.
More info
Run anywayDon’t run

{{FIRST_START_NOTE}} Do not move the folder until the window says Clausa is ready. Then click Open Clausa.

3

Open Clausa.exe

Click New project, name it and choose the language. Click Add recordings, then Start.

Results

Each project is a folder in Documents\Clausa projects\, or in the folder chosen in Settings › Change folder…:

uf_measures.csvthe measures, one row per recording
audio\copies of the recordings
sessions\the TextGrids and the log of each analysis

Open the TextGrids in Praat to check the clauses and pauses.

Problems

Click Log at the bottom of the window to see the log. To report a problem, open an issue on GitHub or email oldriku@proton.me, and attach the analysis's log.txt from its session folder. If Clausa does not open, attach the logs folder from the Clausa folder. Logs contain the recognised words. Send logs and recordings only if you may share them.

Removing Clausa

Close Clausa and delete the Clausa folder. Your projects stay where they are.

Clausa {{VERSION}}

学習者の発話のfluencyをclause単位で測る指標

Clausaは、学習者の発話の録音を分析し、録音ごとに9つのfluency指標を算出します。処理はすべてお使いのPC上で行われ、何もアップロードされません。

始める前に

  • 64ビット版Windows 11、またはMicrosoft EdgeがインストールされたWindows 10。
  • メモリ8GB以上のNVIDIA製GPUがあると、Clausaは数倍速く動作します。ない場合は、録音1件に数分かかります。
  • 16GB以上のメモリ（NVIDIA製GPUがない場合は32GB）。
  • {{FREE_GB}}GBの空き容量。
    • {{MODELS_NOTE_JA}}
  • ClausaフォルダーはOneDrive、Dropbox、Google Driveの中に置かないでください。

セットアップ

1

展開

zipを右クリックしてすべて展開を選び、展開をクリックします。

2

Clausa.exeをダブルクリック

「Windows によって PC が保護されました」と表示されたら、詳細情報をクリックし、次に実行をクリックします。

Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC が危険にさらされる可能性があります。

{{FIRST_START_NOTE_JA}}ウィンドウに「Clausa is ready」と表示されるまで、フォルダーを移動しないでください。表示されたらOpen Clausaをクリックします。

3

Clausa.exeを開く

新規プロジェクトをクリックし、名前を付けて録音の言語を選びます。録音を追加をクリックし、次に開始をクリックします。

結果

各プロジェクトは、「ドキュメント」フォルダー内のClausa projects（または設定 › フォルダーを変更…で選んだフォルダー）の中にある1つのフォルダーです。

uf_measures.csv指標。録音1件につき1行

sessions\各分析のTextGridとログ

TextGridをPraatで開くと、clauseとpauseを確認できます。

問題が起きたら

ウィンドウ下部のログをクリックするとログを表示できます。問題を報告するには、GitHubでissueを作成するか、oldriku@proton.meにメールし、その分析のセッションフォルダーにあるlog.txtを添付してください。Clausaが開かない場合は、Clausaフォルダーのlogsフォルダーを添付してください。ログには認識された単語が含まれるので、ログや録音は、共有に問題がない場合のみ送ってください。

Clausaの削除

Clausaを閉じ、Clausaフォルダーを削除します。プロジェクトはそのまま残ります。

Clausa {{VERSION}}

基于 clause 的学习者口语 fluency 指标

Clausa 分析学习者的口语录音，为每个录音给出九项 fluency 指标。一切都在你的电脑上运行，不会上传任何内容。

开始之前

  • 64 位 Windows 11，或装有 Microsoft Edge 的 Windows 10。
  • 显存 8 GB 或以上的 NVIDIA 显卡可让 Clausa 快数倍。没有显卡时，每个录音需要几分钟。
  • 16 GB 或以上内存（没有 NVIDIA 显卡时 32 GB）。
  • {{FREE_GB}} GB 可用空间。
    • {{MODELS_NOTE_ZH}}
  • Clausa 文件夹不要放在 OneDrive、Dropbox 或 Google 云端硬盘中。

安装

1

解压

右键单击 zip 文件，选择全部提取，然后点击提取。

2

双击 Clausa.exe

如果 Windows 显示“Windows 已保护你的电脑”，点击更多信息，再点击仍要运行。

Windows 已保护你的电脑
Microsoft Defender SmartScreen 阻止了无法识别的应用启动。运行此应用可能会导致你的电脑存在风险。
更多信息
仍要运行不运行

{{FIRST_START_NOTE_ZH}}在窗口显示“Clausa is ready”之前，不要移动文件夹。然后点击 Open Clausa。

3

打开 Clausa.exe

点击新建项目，为项目命名并选择录音语言。点击添加录音，再点击开始。

结果

每个项目是“文档”文件夹中 Clausa projects（或在设置 › 更改文件夹…中选择的文件夹）里的一个文件夹：

uf_measures.csv指标，每个录音一行
audio\录音的副本
sessions\每轮分析的 TextGrid 和日志

在 Praat 中打开 TextGrid，检查 clause 和 pause。

问题

点击窗口底部的日志可查看日志。要报告问题，请在 GitHub 上提交 issue，或发邮件到 oldriku@proton.me，并附上该次分析的 log.txt（在其分析轮次的文件夹中）。如果 Clausa 无法打开，请附上 Clausa 文件夹中的 logs 文件夹。日志包含识别出的单词。请确认可以分享后，再发送日志和录音。

卸载 Clausa

关闭 Clausa，然后删除 Clausa 文件夹。你的项目会留在原处。
